**Shaikh Shahab Restaurant Website 🍽️**

A simple restaurant website created using HTML tags. It features a restaurant menu organized into different categories, including Chicken, Beef, Mutton, BBQ, Fast Food, Desserts, Drinks, and more. It also includes an Online Order section.

**Technologies Used:**
- HTML5

**Project Purpose:**
This project was created to practice HTML tags and learn how to structure a restaurant website using headings, lists, and links.
